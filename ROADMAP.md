# Marketing Bot Roadmap

## Deferred by request

These improvements were selected but intentionally postponed while animated
slides and multi-hook scoring are implemented first:

1. Introduce real app footage earlier in each post: pain, consequence, actual
   app interaction, result, proof, and CTA.
2. Organize local music by mood and select tracks based on the generated
   content style instead of choosing from one shared folder.
3. Build a performance feedback loop using retention, rewatches, profile visits,
   store clicks, installs, and first useful in-app actions, then use winning
   patterns to guide future generation.
